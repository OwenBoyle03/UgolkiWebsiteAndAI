# CS408 Project Work - Owen Boyle

In order to run the Ugolki website all you need access to is the Inteliji IDE.
For the JavaScript tests you must install Jest which allows the JavaScript tests to run.
Before you run the tests you need to uncomment the module.import at the bottom of the file to be tested.

Any of the python AIs run natively in any python editor of your choice.
To run the python tests you must use pip to install pytest.
